# 实验（训）9 MUX-VLAN：验证命令（两台交换机）
#
# 下发方式：
#   enspctl run LSW1 --file examples/mux-vlan/lab9/lsw1.cfg --root <lab 目录>
#   enspctl run LSW2 --file examples/mux-vlan/lab9/lsw2.cfg --root <lab 目录>
#
# 每条命令都会校验回显，没被执行会直接报错。

# ---------- LSW1 ----------
# 1) MUX-VLAN 总表：主/从 VLAN、类型、成员接口
display mux-vlan

# 2) VLAN 表：确认 10/20/30 是 mux-sub（从 VLAN）、100 是 mux（主 VLAN）
display vlan

# 3) 各接口的 VLAN 归属与 MUX-VLAN 使能状态
display port vlan

# 4) 互联口（trunk）放通了哪些 VLAN
display vlan 10

# ---------- LSW2 ----------
# 5) 接入侧的 VLAN 归属
display vlan

# 6) 跨交换机的二层通路：LSW1 上应学到 LSW2 的 MAC（VLAN 10 / GE0/0/5 / dynamic）
display mac-address

# ---------- 终端侧（PC 的命令行）----------
